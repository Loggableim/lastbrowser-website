Short description (boilerplate)

LastBrowser is the first AI-native web browser for Windows and Linux (Linux preview) with a true ConPTY PowerShell terminal, Castlabs Widevine DRM L3 and isolated multi-account Spaces. It combines state-of-the-art AI workflows (BYOK & MCP) with uncompromising Local-first privacy without involuntary telemetry.

Founder statement

“Traditional browsers treat AI like a bolted-on chatbot and developers like mere consumers. We built LastBrowser to fuse the command line, vertical organization and local AI models directly into the Windows shell – without letting sensitive data end up in third-party clouds.”

— Rainer Dominik, LastBrowser initiator
