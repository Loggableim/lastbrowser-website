Unified Extension & Skill Ecosystem

Catalog of 48 Agentic Workflows & MCP

Extend Sidekick with specialized agentic skills for research, coding, data analysis and content creation, or connect external MCP servers with one click.

Curated external MCP servers

Copy the ready-made JSON definitions directly into your mcp_servers.json.

🐘 PostgreSQL Database Server

Database

Lets Sidekick run read-only queries against table schemas and execute SQL queries for data analysis.

JSON configuration 
{
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://user:pass@localhost/db"]
}

📂 Windows Filesystem Server

System tool

Allows Sidekick to browse, read and write source-code files in shared project directories.

JSON configuration 
{
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\Projekte"]
}

🐙 GitHub Repository Tool

DevOps

Review pull requests, search issues and analyze branch changes directly from the browser.

JSON configuration 
{
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-github"],
  "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "YOUR_TOKEN" }
}

🗺️ Google Maps Geocoding

Geo data

Enables address checks, distance calculations and geocoding directly during web research.

JSON configuration 
{
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-google-maps"],
  "env": { "GOOGLE_MAPS_API_KEY": "YOUR_KEY" }
}

The 48 built-in agentic skills

Each skill is a modular prompt and tool workflow in the in-tree Python Sidekick engine.

🔬 1. Research & Analysis (12 skills)

Paper Summarizer

PDF

Compresses complex arXiv and ScienceDirect PDFs into core statements and hypotheses.

Multi-Source Fact Checker

Web

Compares claims across different news sources and flags contradictions.

Competitive Intelligence

Market

Extracts pricing models, feature tables and target audiences from competitor websites.

Patent Analyzer

Legal

Analyzes claims and technical specifications in patent databases.

💻 2. Code & Developer Tools (12 skills)

OpenAPI / Swagger Extractor

API

Detects API definitions in the DOM and generates typed TypeScript clients or cURL commands.

Regex Visualizer & Debugger

Syntax

Explains regular expressions step by step and tests them interactively against web content.

Stacktrace Resolver

Doctor

Analyzes error output in the ConPTY terminal and suggests immediate code fixes.

CSS Glassmorphism Styler

Design

Generates modern Tailwind or vanilla CSS backdrop filters with exact color matching.

Tone & Style Adapter

SEO Meta-Tag Architect
