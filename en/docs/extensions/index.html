Chrome MV3 Extensions & Dev Guide

LastBrowser is based on the browser engine and fully supports the modern Chrome Extension Manifest V3 (MV3) standard. You can use your favourite extensions (uBlock Origin, Bitwarden, React Developer Tools, etc.) directly.

Install from the Chrome Web Store

Open the official Chrome Web Store in LastBrowser and click “Add” as usual. LastBrowser integrates the extension into the native menu bar.

Load unpacked extensions (developer mode)

For extension developers, LastBrowser offers a fast reload cycle for unpacked directories:

  1. Press Ctrl + Shift + X to open the Unified Extension Hub.
  2. Enable the “Developer mode” switch.
  3. Click “Load unpacked extension” and select the folder containing your manifest.json.

Supported Chrome APIs

LastBrowser implements the extension standard including:

  • chrome.runtime, chrome.tabs, chrome.storage
  • chrome.declarativeNetRequest (efficient ad and tracking blocking)
  • chrome.contextMenus, chrome.action
  • chrome.cookies (respecting the active Space partition)
