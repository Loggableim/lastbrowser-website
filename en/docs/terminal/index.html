Integrated ConPTY Windows Terminal

LastBrowser integrates the modern Windows Pseudo-Console (ConPTY) directly into the browser shell. Developers get a real terminal with full ANSI colour support, xterm.js rendering and PowerShell Core support.

Open & control the terminal

  • Ctrl + ` : open / minimize the terminal drawer
  • Ctrl + Shift + C : copy selected text in the terminal
  • Ctrl + Shift + V : paste text into the terminal

Supported shells

By default, LastBrowser launches the native 64-bit PowerShell.exe. In the settings you can freely choose your preferred shell:

  • PowerShell 7 (pwsh.exe) (if installed)
  • Windows PowerShell 5.1 (default on all Windows 10/11 systems)
  • Command Prompt (cmd.exe)
  • Windows Subsystem for Linux (wsl.exe)

Terminal Doctor: automatic error analysis

When a command exits with an error code (e.g. a failed npm install or Python stack trace), the integrated Terminal Doctor shows a subtle diagnosis bar:

🩺 Doctor recommendation

Missing dependency typescript detected.

Suggested command 
npm install --save-dev typescript
