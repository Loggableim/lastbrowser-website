Local Filesystem & Configuration

LastBrowser stores all application data locally on your PC. No unsolicited data is transmitted to cloud services.

Storage paths on Windows 
%APPDATA%\Lastbrowser\
├── config.json         # Browser settings & themes
├── mcp_servers.json    # Model Context Protocol configurations
├── spaces\             # Isolated partition data per Space
│   ├── default\        # Cookies, cache, IndexedDB
│   └── work\           # Separate cookie jar
└── secrets\            # API keys encrypted with Windows DPAPI
