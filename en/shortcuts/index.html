Keyboard Productivity Guide

Keyboard Shortcuts Cheat Sheet

Control LastBrowser at lightning speed without a mouse. All hotkeys are optimized for Windows.

Key combination Action / function Category
Ctrl + B Show or hide the vertical sidebar (full reading mode) Sidebar
Ctrl + ` Show or hide the ConPTY PowerShell terminal Terminal
Ctrl + Shift + L Show or hide the Sidekick copilot in 70/30 split-view AI / Sidekick
Ctrl + Shift + X Open the unified extension & MCP Hub Extensions
Ctrl + T Open a new tab in the active Space Tabs
Ctrl + W Close the active tab Tabs
Ctrl + Shift + T Restore the last closed tab in the active Space Tabs
Ctrl + Tab Switch to the next open tab Tabs
Ctrl + 1 ... 9 Jump directly to tab 1 to 9 in the active Space Tabs
Ctrl + L Focus the address and search bar (omnibox) Navigation
Ctrl + R Reload the current page Navigation
Ctrl + F Open the in-page search bar on the current page Search
F12 Open developer tools Developer
