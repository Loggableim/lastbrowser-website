🪐 LastBrowser VS Arc Browser

The modern Arc alternative for Windows

After The Browser Company stopped active Arc development for Windows, many users are looking for a real alternative. LastBrowser is built natively for Windows 10 & 11.

Switch to LastBrowser (.exe) Compare features

LastBrowser

Active Windows Development
  • ✓ Fully native Windows focus: Perfectly optimized for Windows 10 & 11 with Snap Layouts and ConPTY.
  • ✓ Real ConPTY terminal: Integrated PowerShell/CMD right in the sidebar with Ctrl+`.
  • ✓ Local-first & GDPR: No forced cloud. All data stays local in %APPDATA%.
  • ✓ Flexible model choice: Configure available providers or use local Ollama models.
  • ✓ Castlabs Widevine DRM L3: Flawless HD streaming on Netflix, Spotify & Disney+.

Arc for Windows

Discontinued / Maintenance Mode
  • ✕ Development discontinued: No new core features for Windows; focus on Dia/macOS.
  • ✕ No terminal: No integrated developer terminal in the UI.
  • ✕ Cloud lock-in: Arc Sync requires a cloud account and sends history to servers.
  • ✕ Proprietary AI: No support for your own API keys or local Ollama models.
  • ✕ Unstable Windows port: Known performance and DRM issues on Win32.

Why switching to LastBrowser pays off

If you love the vertical sidebar and isolated Spaces concept but want a future-proof, privacy-friendly, developer-oriented solution on Windows, LastBrowser is your ideal companion.
