Built for Software Engineers & DevOps

The browser that thinks like an IDE

Stop constant alt-tabbing between documentation, web apps and the terminal. LastBrowser integrates a real ConPTY Windows terminal, OpenAPI extractors and Model Context Protocol (MCP) right into the browser.

Download LastBrowser for developers Read terminal docs
💻

Real ConPTY Terminal

A full Windows pseudo-terminal in the sidebar. Run git, npm, cargo or docker right next to live localhost apps (Ctrl+`).

🩺

Terminal Doctor

Automatic error diagnostics for failed builds or stack traces. The built-in Doctor analyzes error messages and suggests fix commands.

🔌

Model Context Protocol (MCP)

Connect local and external MCP servers (PostgreSQL, filesystem, GitHub) with one click. Give AI direct access to your developer tools.

🦙

Full Offline Support via Ollama

Work offline on a plane or in high-security networks. Plug in local Ollama models (Llama 3, DeepSeek Coder, Qwen) with low latency.

📄

OpenAPI & GraphQL Extractor

Sidekick automatically detects API documentation on websites and exports clean TypeScript types, curl commands or Postman collections.

🪐

Isolated Localhost Spaces

Test frontend and backend under different auth roles at the same time on localhost:3000 without clearing cookies manually.

Connect an MCP Server in 1 Click

Configure MCP servers in your mcp_servers.json directly under %APPDATA%\Lastbrowser:

mcp_servers.json 
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://localhost/mydb"]
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\Projekte"]
    }
  }
}
