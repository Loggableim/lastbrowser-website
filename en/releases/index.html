v0.1.59 · 2026-10-22

Published on October 22, 2026. The installer is significantly smaller (about 300 MB instead of about 610 MB) as model files are no longer bundled. Setup and Portable are signed with a Certum certificate; checksums see download page (SHA-256).

v0.1.58 · 2026-10-17

Published on October 17, 2026. Beta update subscription with a notice about unsigned daily builds; release pipeline for the daily beta and stable channels; desktop build fix with pinned Python runtime dependencies for Sidekick. Setup and Portable are Authenticode-signed (Certum); checksums see SHA256SUMS.

Setup / Portable · SHA-256 · GitHub release

v0.1.55 · 2026-10-12

Published on October 12, 2026. Default chat can be stopped while starting; quick chat shows stop while searching models. Model catalogs are reused per profile and configuration. Known limitations: on first start a black area may appear until Ctrl+R; the signed build has not yet been accepted in the VM. An improvement in chat latency is not confirmed.
