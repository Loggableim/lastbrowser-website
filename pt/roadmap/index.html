Ciclo de versões

Próxima beta: 0.1.57 hoje, 16.10.2026, 20:00 no horário de Viena. Depois uma beta nova por dia: 17.10 é 0.1.58, 18.10 é 0.1.59.

Próxima janela de release: quinta-feira, 22.10.2026, 16:20. A beta diária anterior é 0.1.62. O release salta para a dezena seguinte, ou seja 0.1.70. Depois as betas seguem: 23.10 é 0.1.71, 24.10 é 0.1.72. Em 5.11.2026 o salto seria 0.1.90. Sem tag estável até Cid nomear a beta.

O aplicativo pode assinar o canal Stable ou Beta. As betas não são assinadas a cada envio.

A beta 0.1.57 é preparada a partir de lastbrowser/demo4-final-b614 @ ae4a3679. Sem assinatura e sem tag estável.

A primeira quinta de release esta marcada: 22.10.2026, 16:20. Depois a cada duas semanas: 5.11. salta para 0.1.90 e 19.11. para 0.1.110.
