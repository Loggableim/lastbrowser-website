Cycle de versions

Prochaine bêta : 0.1.57 aujourd'hui, 16.10.2026, 20:00 heure de Vienne. Puis une bêta nouvelle chaque jour : le 17.10 est 0.1.58, le 18.10 est 0.1.59.

Prochaine fenêtre de release : jeudi 22.10.2026, 16:20. La bêta quotidienne d'avant est 0.1.62. La release saute à la dizaine suivante, donc 0.1.70. Les bêta reprennent ensuite : le 23.10 est 0.1.71, le 24.10 est 0.1.72. Le 5.11.2026 le saut serait 0.1.90. Pas d'étiquette stable tant que Cid n'a pas nommé la bêta.

L'application peut s'abonner au canal Stable ou Bêta. Les bêtas ne sont pas signées à chaque envoi.

La bêta 0.1.57 est préparée depuis lastbrowser/demo4-final-b614 @ ae4a3679. Non signée, pas d'étiquette stable.

Le premier jeudi de release est fixe : 22.10.2026, 16:20. Puis toutes les deux semaines : le 5.11. saute a 0.1.90 et le 19.11. a 0.1.110.
